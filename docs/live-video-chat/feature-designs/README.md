## 资深后端面试视角的待补充方向

- 推荐系统与 Feed 流架构
- 事件采集、Kafka 和 OLAP 分析

- 热点内容缓存和多级缓存

- 账号风控、反作弊、反刷量
- 高可用、容灾、备份、RPO/RTO 和故障演练
- API 网关、BFF、移动端 API 版本治理
- CI/CD、灰度发布、配置治理
- 视频业务成本模型
- 数据库分区、归档和冷热数据治理
